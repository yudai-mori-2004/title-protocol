## 概要 (拘束力のない平易な要約)

- **著作権は引き続きあなたのものです。** アップロードしても発行 (ミント) しても、著作権が当社に移ることはありません。
- **当社はマーケットプレイスを提供し、あなたが売主となります。** 購入者は、ファイルの複製と「License NFT」(その複製で何ができるかを記録する NFT) を受け取ります。購入者は USDC で、あなたのウォレットに直接支払います (当社が事前に開示したプラットフォーム手数料は控除されます)。
- **価格はあなたが決めます。** 当社は市場データから計算した推奨価格を表示することがありますが、発行のたびにあなたが上書きできます。
- **あなたは、コンテンツが自分のもので、適法で、第三者の権利を含まないことを表明します。** これが事実でなかったために第三者から当社が訴えられた場合、あなたが当社の合理的な費用を負担します (第10条)。
- **AI 学習はオプトインです。** あなたのコンテンツには機械可読の「学習禁止」信号が付与されます。AI 学習を許可する唯一の手段は `training-only-v1` ライセンスを販売することです。なお、購入者の AI が後に生成する出力の適法性は当社もあなたも保証しません — 出力は購入者の設計に依存します (第6条6項)。
- **発行 (ミント) は不可逆です。** Solana 上に Root NFT が発行された後は、あなたも当社もこれを削除できません。
- **停止・キャンセル。** アプリの利用を止めれば新規送信は止まります。既に発行した Root NFT について将来の License NFT 発行を止めたい場合は、当該 Root NFT をバーンアドレスまたはあなたが支配しないウォレットに移転してください (第6条10項)。既に発行された License NFT はその条件に基づいて存続します。
- **当社はインフラ提供者であり、保険会社ではありません。** 強行法令が要求する水準を超えて損害を補償することはありません (第12条)。責任は三層構造です。あなたが著作権の帰属を表明します。当社は本人確認 (KYC) 手続きと技術運営を行います (第4条3項)。購入者はライセンス範囲内での適法な利用について責任を負います。
- **紛争解決。** 原則として**シンガポールでの SIAC 仲裁**により、一件ずつ個別に解決します。**集団訴訟は禁止です** (第16条)。**EEA、英国、スイス、日本に居住する消費者の方には、自国裁判所への提訴権および自国の消費者保護法の適用権を維持します** (第2条の2)。
- **違法コンテンツの通報、お問い合わせ。** 第18条記載の電子メールアドレスにご連絡ください。
- **バージョン管理。** 各 Root NFT は、ミント時点で TEE に埋め込まれていた本規約のバージョンに固定されます。以後の改訂は過去のミントには適用されません。
- **当社のサービスが終了する場合、** あなたの Root NFT および License NFT は Solana 上に存続します。当社は90日前までの通知と、分散型ストレージへのライセンス文書複製による保全に努めます (第15条3項)。
- **アプリで表示される内容が拘束します。** 万一アプリが誤って異なるバージョンを表示し、あなたが善意でそれに同意した場合、あなたが実際に見たバージョンが優先されます。ただし、それがあなたの権利を縮減する方向には作用しません (第17条9項(4))。

## 第1条 (定義)

1項 **「当社」**、**「RootLens」**または**「我々」**とは、第18条に記載する事業者をいい、現時点では森雄大が屋号「moodai」をもって営業する個人事業をいう。

2項 **「ユーザー」**または**「クリエイター」**とは、本規約に同意し、コンテンツを送信する自然人をいう。

3項 **「コンテンツ」**とは、RootLens アプリケーションを用いて撮影され、処理のためにユーザーが送信した画像、動画その他のデジタルファイルをいう。

4項 **「RootLens アプリケーション」**とは、当社が公開する、クリエイターがコンテンツを撮影・送信するためのモバイルまたはウェブアプリケーションをいう。

5項 **「TEE」**とは、当社が運用する Trusted Execution Environment (信頼実行環境) であって、Title Protocol ソフトウェアを実行し、コンテンツを処理し暗号学的なアテステーション (証明文書) を生成するものをいう。

6項 **「Root NFT」**とは、特定のコンテンツに対し TEE が Solana ブロックチェーン上に発行する非代替性トークンであり、当該コンテンツが本規約に基づく RootLens の処理を経たことを表すものをいう。

7項 **「License NFT」**とは、第6条5項に定める定型ライセンステンプレートに基づき発行される別の Solana NFT であり、特定のコンテンツに関する指定された権利を当該 License NFT 保有者に付与するものをいう。

8項 **「コンテンツ真正性信号」**または**「信号」**とは、コンテンツに付与された C2PA マニフェストに埋め込まれる機械可読のメタデータ (技術仕様上は CAWG training-mining アサーション) であって、EU 指令 2019/790 (**「CDSM 指令」**) 第4条第3項およびこれに類する法令に基づき、テキスト・データマイニング (**「TDM」**) および AI 学習への利用に対する権利留保を示すものをいう。

9項 **「適用バージョン」**とは、Root NFT 発行の時点で TEE の署名付きアテステーション (証明書) に記録された本規約のバージョン番号をいう。当該 Root NFT には、その存続期間にわたり当該バージョンが適用される。

10項 **「正本ハッシュ」**とは、本規約のひとつの特定バージョンを一意に識別する SHA-256 の指紋値をいい、第17条9項に定める手順で算出する。

11項 **「消費者」**とは、商業、事業、技能または職業の範囲外で行為する自然人をいう。

## 第2条 (同意)

1項 RootLens アプリケーションは、コンテンツを処理する前に2つの別個の同意画面を表示する。

   (1) **規約への同意。** 第1画面で「規約に同意する」をタップすることにより、本規約はユーザーと当社との間の法的拘束力ある合意として成立する。本ステップは契約の成立のみに関する。

   (2) **個人データ処理の説明。** 第2画面では、ユーザーの同意を立証するために当社が処理する個人データ (ウォレット公開鍵、IP アドレス、ユーザーエージェント、タイムスタンプ)、各処理の法的根拠、ユーザーの権利を説明する。本画面で任意の選択をしなくても本規約を読みコンテンツを送信することができる。契約の履行および同意の立証に必要なデータ処理は、同意ではなく第13条に定める法的根拠に基づき行われる。

2項 ユーザーが本規約に同意しない場合、RootLens アプリケーションはコンテンツを TEE に送信しない。

3項 コンテンツを送信する各行為は、当該送信に適用バージョンの本規約が適用されることを再確認する行為でもある。適用バージョンとは、当該送信を処理する TEE に埋め込まれたバージョン定数をいう。

4項 **EEA・英国消費者による撤回権の放棄確認。** EEA、英国またはスイスに通常居住する消費者は、距離契約からの14日間の撤回権を有する。Root NFT の発行はオンチェーン上の不可逆的操作である。「Mint Now」をタップすることにより、ユーザーは当社が直ちに履行を開始することを明示的に要求し、ミントが開始された後は、EU 指令 2011/83 第16条(m) および英国 Consumer Contracts (Information, Cancellation and Additional Charges) Regulations 2013 第37条に基づく14日間撤回権を失うことを了承する。
