# Fixture Factory

Generates C2PA-signed and unsigned test fixtures from minimal source files.

## Usage

From the project root:

```bash
cargo run --example gen_c2pa_fixtures
```

This regenerates all fixtures under `tests/fixtures/c2pa/` and `tests/fixtures/minimal/`.

## Implementation

The factory is implemented as a Cargo example in `crates/core/examples/gen_c2pa_fixtures.rs` (Cargo requires examples to live within a crate directory).

## What it generates

| Directory | Content | Count |
|-----------|---------|-------|
| `c2pa/signed/` | C2PA-signed files (JPEG, PNG, TIFF, WAV, MP3, MP4) at various sizes | 16 |
| `c2pa/unsigned/` | Same formats without C2PA manifests (for error tests) | 8 |
| `minimal/` | Source files used as factory input (generated by ffmpeg) | 9 |

## What it does NOT generate

External fixtures that require real hardware/vendor signing:

- `images/jpeg/pixel_*.jpg` — Google Pixel C2PA-signed (committed manually)

## Dependencies

- `ffmpeg` — for generating MP4, MP3, and JPEG test sources
- Test CA certificates at `tests/fixtures/certs/` — for C2PA signing
